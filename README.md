# 🛡️ Hybrid Spam & Phishing Detection System

A multi-layered threat detection system engineered for high-accuracy email classification. This system combines **Network-Level Cybersecurity Heuristics (URL inspection, redirect un-shortening, and WHOIS domain age verification)** with **Natural Language Processing and Machine Learning (TF-IDF + Multinomial Naive Bayes)** to defend against sophisticated spam and zero-day phishing campaigns.

---

## 📌 System Architecture & Hybrid Rationale

Traditional spam filters and standalone machine learning models suffer from a fundamental vulnerability: **zero-day evasion attacks**. Attackers frequently compose grammatically clean, convincing emails embedded with newly purchased domains (often registered within minutes of the attack). A pure ML model trained on linguistic tokens may falsely classify these deceptive messages as legitimate ("Ham").

To counter this, our system implements a **fail-fast hybrid pipeline**:

```
[ Inbound Email / Text ]
          │
          ▼
┌──────────────────────────────────────────────┐
│  Stage 1: Cybersecurity & URL Intelligence   │
│  - Regex URL Extraction                      │
│  - HTTP Redirect Resolution (5s timeout)     │
│  - Base Domain Extraction (tldextract)       │
│  - WHOIS Domain Age Query (python-whois)     │
└──────────────────────────────────────────────┘
          │
          ├───────── Domain Age < 30 Days? ─────────┐
          │                                         │
        [ No / Safe ]                             [ Yes ]
          │                                         │
          ▼                                         ▼
┌──────────────────────────────────────┐  ┌──────────────────────────────────┐
│  Stage 2: Machine Learning NLP Engine│  │ 🚨 HALT PIPELINE: PHISHING ALERT │
│  - NLTK Tokenization & Stopwords     │  │ - Threat Score: 100/100         │
│  - Punctuation & Case Normalization  │  │ - ML Inference Bypassed          │
│  - TF-IDF Vectorizer (3,000 features)│  │ - Immediate High-Risk Banner     │
│  - Multinomial Naive Bayes Classifier│  └──────────────────────────────────┘
└──────────────────────────────────────┘
          │
     ┌────┴────────────┐
     ▼                 ▼
[ ⚠️ SPAM ]       [ ✅ HAM ]
(Promotion/Junk)  (Legitimate)
```

1. **Stage 1 (Cybersecurity Interceptor):** Evaluates all hyperlinked entities. If a domain is registered less than **30 days ago**, it is flagged as a zero-day phishing vector. The ML process is **purposefully halted** to eliminate false-negative risk.
2. **Stage 2 (Machine Learning Engine):** When links are either established or absent, the text is cleaned, tokenized, transformed into a 3,000-dimensional TF-IDF feature space, and evaluated by an 80/20 train-tested **Multinomial Naive Bayes** classifier (~97.2% test accuracy).

## ⚙️ Local Setup & Installation

### Prerequisites
- Python 3.10+ installed
- Internet connectivity (for initial WHOIS lookups and dataset download)

### Step 1: Clone / Navigate to Project Directory
```bash
cd "fai mini project"
```

### Step 2: (Recommended) Create a Virtual Environment
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### Step 3: Install Required Dependencies
```bash
pip install -r requirements.txt
```

### Step 4: Train the Machine Learning Engine
Run the training script to fetch the public SMS Spam Collection dataset, compute TF-IDF features, evaluate model performance, and export `spam_model.pkl` and `vectorizer.pkl`:
```bash
python train_model.py
```
*Expected Output:*
- Downloads NLTK resources and dataset.
- Evaluates test accuracy (~**97.2%**).
- Saves `spam_model.pkl` and `vectorizer.pkl`.

### Step 5: Launch the Streamlit Web Application
```bash
streamlit run app.py
```
Open your browser to `http://localhost:8501`.

## 🐳 Docker Containerization & Deployment

The application is containerized with a production-optimized `python:3.11-slim` base image, internal NLTK asset caching, automated model artifact verification, and built-in healthchecks.

### 1. Build the Docker Image
```bash
docker build -t hybrid-spam-phishing-shield:latest .
```

### 2. Run the Container
```bash
docker run -d -p 8501:8501 --name spam-detector hybrid-spam-phishing-shield:latest
```

### 3. Access the Application
Navigate to `http://localhost:8501` in your web browser.

To stop the container:
```bash
docker stop spam-detector && docker rm spam-detector
```
